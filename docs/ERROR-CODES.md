# Kode error

Satu tabel per kode yang bisa dikembalikan layanan. Pemetaan HTTP dan pesan
pengguna untuk booking ada di `src/lib/booking/errors.ts`; teks mentah
Postgres tidak pernah diteruskan ke klien. Satu tabel untuk semua lapisan.
Kolom Kode memuat kode stabil (`error` di JSON atau `code` Postgres); baris
terakhir per lapisan server action berisi pemetaan lokalnya. Kode yang tidak
dikenal selalu jatuh ke pesan umum lapisannya dan dicatat di log. Catatan
ketidakkonsistenan antarlapisan ada di bagian akhir.

## Catatan ketidakkonsistenan (tidak ada kode yang diubah)

1. BK080, BK081, dan 42501 pada simpan tautan link-in-bio dipetakan oleh `src/lib/funnel/links-errors.ts` (42501 "Sesi Anda berakhir atau tautan bukan milik akun ini. Muat ulang halaman lalu coba lagi."; lainnya "Perubahan gagal disimpan. Coba lagi sebentar lagi.").
2. Satu kode punya beberapa kalimat menurut lapisan (23P01, BK001, BK003, BK060, BK061, BK072). Ini disengaja (nada publik, pelanggan, merchant) dan tabel ini harus mengikuti ketiga peta: `errors.ts`, `customer-manage.ts`, `manual-booking.ts`.
3. `customer-manage.ts` (jadwal ulang pelanggan) tidak memetakan BK070, BK071, BK063, 22023, dan 42501. Saat ini RPC `reschedule_booking` tidak menaikkannya, tetapi bila menaikkan, hasilnya 500 "Gagal menyimpan. Coba lagi." Rute `ubah-jadwal` kini mengirim `code` mesin stabil di samping `error` (lihat baris `ubah-jadwal` di atas); 409 untuk semua kode terpetakan, termasuk kebijakan (BK040 sampai BK046), dan 500 `save_failed` untuk sisanya.
4. `rescheduleErrorMessage` (merchant) tidak memetakan 22023, 42501, dan BK071; semuanya jadi "Gagal menyimpan. Coba lagi." Tidak ada status HTTP karena server action.
5. 23505 pada `POST /api/bookings` jatuh ke 500 umum (tidak ada unique yang bisa dipicu publik); pada server action lapangan dan onboarding ia dipetakan (nama ganda, username).
6. `POST /api/vouchers/check` memakai `mapBookingError`, jadi BK054 dan BK071 mengikuti peta booking. Galat bawaannya: 400 "Data kode voucher tidak valid", 404 "Merchant tidak ditemukan", 429 (batas cek kode), 503 "Pemeriksaan kode sedang gangguan. Coba lagi sebentar.", 500 "Gagal memuat data merchant". Kodenya belum punya `code` mesin stabil, hanya teks (ditunda).
